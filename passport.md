Паспорт приложения и целевой платформы

1. Паспорт приложения

Название: Disk Check Service  
Версия: v1.0.0  
Назначение: HTTP-сервис мониторинга использования дискового пространства. Предоставляет API для получения информации о диске и проверки состояния системы.  
Пользователи: Администраторы системы, мониторинговые системы.  
Входы: HTTP GET запросы на порту 8109.  
Выходы: JSON-ответы с информацией о диске и статусе системы.  
Состав версии: app.py, disk_check.py, Dockerfile, compose.yaml, settings.json.example, README.md.  
Зависимые компоненты: Python 3.12, Docker, Docker Compose.  
Данные: JSON-файл состояния /data/state.json (счётчик запросов).  
Критерии приемки: 
- Сервис отвечает на GET /health кодом 200 и {"status": "ok"}.  
- Сервис отвечает на GET /disk информацией о диске.  
- Сервис работает в контейнере с лимитом памяти 128 Мбайт.  
- Healthcheck проходит успешно.

2. Паспорт целевой платформы
Сценарий: Платформа с лимитом 128 Мбайт на контейнер.  
Операционная система: Windows 11 (хост), Ubuntu 22.04 (контейнер).  
Архитектура процессора: x86-64.  
Оперативная память хоста: 16 Гбайт.  
Дисковое пространство хоста: 512 Гбайт SSD.  
Контейнерный движок: Docker Desktop 4.x с Compose v2.  
Открытые порты: 8109 (маппинг на 8009 внутри контейнера).  
Лимиты контейнера:
- Память: 128 Мбайт (mem_limit).  
- CPU: 0.5 ядра (cpus).  
Места хранения данных:
- Именованный том disk-data для /data.  
- Read-only том ./readonly-data для /readonly.
