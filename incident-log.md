Журнал события: Отказ и восстановление Disk Check Service

Дата и время
- Отказ: 2026-11-22, 14:30
- Восстановление: 2026-11-22, 14:35

Описание отказа
Снижение лимита памяти контейнера с 256 Мбайт до 1 Мбайт привело к невозможности запуска приложения. Контейнер перешёл в статус Exited/Restarting.

Причина отказа
Недостаточный лимит памяти (1 Мбайт) для работы Python HTTP-сервера. Приложение требует минимум ~50-60 Мбайт для запуска.

Действия по восстановлению
1. Остановлен контейнер: docker compose down
2. Изменён лимит памяти в compose.yaml: 32m -> 128m
3. Запущен контейнер: docker compose up -d
4. Проверен healthcheck: curl http://localhost:8109/health
5. Проверены лимиты: docker stats disk-v1 --no-stream

Результат
Сервис восстановлен. Healthcheck проходит. Потребление памяти в пределах лимита 128 Мбайт.

Вывод
Лимит памяти 256 Мбайт является минимально достаточным для работы приложения. Снижение до 1 Мбайт приводит к отказу.
